## 3. 价格口径与缺失项（严格按实际返回解释）

**机票**
- 实际返回的价格字段是 `ticketPrice`（字符串，如 `"929.00"`），**响应里没有 `adultPrice`／`childPrice`／`price` 字段**（官方 references 示例中的 `adultPrice` 在本次真实返回中不存在）。
- 响应未标注币种符号、未拆"票价／机建／燃油／服务费"，也未给"每人"或"整单"的口径说明。`--max-price` 文档写明单位为 CNY，故本报告把 `ticketPrice` 读作**人民币元、单张经济舱票面价**，但**是否已含税费无法从返回中确认**——预算表中据此标记为"待核验"。
- `quantity`、`miles`、`tags`、`stopInfos` 全为 `null`；**没有座位余量、行李额、退改规则、可订状态字段**。因此本报告**不声称任何航班"可预订"或"有票"**。
- 排序参数 `--sort-type 3`（价格低→高）已生效：去程 856→1069、返程 330→500 单调递增。

**酒店**
- `price` 形如 `"¥140"`，带币种符号；`search-hotel` 的 `--max-price` 文档口径为**每晚人民币价**，故读作**每间每晚**。但响应未明确"是否含税/含早""几大床型""是否需补差价"，也未给 3 晚合计价——报告中的住宿合计是 `price × 3 晚` 的**推算**，不是接口直接返回的总价。
- `score`、`scoreDesc`、`review`、`rate`、`commissionMoneyYuan` 在本次返回中全部为 `null` → **无评分、无评价、无佣金数据**，因此不能对"哪家更好"下结论，只按价格与位置客观排列。
- 无库存／可订／房型／床型字段 → **不声称任何酒店"有房"**。
- `systemMessage` 三次查询均为 `null`（本次无平台提示）。
- `jumpUrl`／`detailUrl` 是 `router.feizhu.com` 短链，指向飞猪落地页；**链接有效期与最终价格以打开时页面为准**。
